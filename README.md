## ✨ What This Card Does

flight-board-card is a custom card for Home Assistant dashboards. It gives you an airport-style display for departures and arrivals without needing to build the layout yourself. The card is designed to feel like a real flight board: clear rows, readable flight information, airport search, and a style that fits wall-mounted screens.

The card uses the Flightradar24 integration, so the flight information you show comes from the same kind of data many aviation fans already use. Airport search makes it easier to find the airport you want and display the right board for your dashboard.
